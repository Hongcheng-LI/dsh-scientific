# 文献综述工作流

配合工具：`tool-zotero`（zotero_search / zotero_item / zotero_fulltext）、dsh-synbio（synbio_paper_search / synbio_paper_abstract）。

## 流程

1. **界定范围**（先问清，不确定就问）：
   - 主题与关键词（中英文各一组）
   - 时间范围（默认近 5 年）
   - 是否限定综述/研究论文/方法论文
2. **广撒网**：`synbio_paper_search` 用主题词 + 年份区间检索，记录命中总数；换 2-3 组同义词补充检索（避免单一关键词漏检）。
3. **筛选**：按标题+摘要筛掉不相关条目；输出筛选清单（纳入/排除及理由，一篇一行）。
4. **精读**（纳入 ≥5 篇时）：对关键文献用 `synbio_paper_abstract` 或 Zotero 全文提取——研究问题/方法/核心数据/结论。
5. **交叉对比**：按维度列表格（方法、体系、关键数值、结论），指出共识、分歧与空白。
6. **综述报告**：结论先行；每条论断标注出处（作者, 年份, DOI）；末尾给"研究空白与机会"小节。

## 原则

- 检索词组合与命中数必须如实报告，不得隐瞒低命中。
- 数值结论必须回原文核对，摘要与正文冲突时以正文为准。
- 区分"作者声称"与"数据支持"，表述上明确区分。
