# 批量对接（虚拟筛选）

配合工具：`tool-vina`（vina_version / vina_dock），文件准备用 shell（OpenBabel/ADFR 如已安装）。

## 流程

1. **前置检查**：`vina_version` 确认 Vina 可用；确认受体 PDBQT 与配体库（.pdbqt 列表或可用 obabel 批量转换）。
2. **口袋定义**（关键，先和用户确认）：
   - 有共晶配体：以配体质心为盒子中心，盒子边距 +6~8 Å；
   - 无配体：文献报道的活性位点残基，或让用户给坐标；
   - 盒子尺寸一般 20~28 Å，写入记录（中心+尺寸+依据）。
3. **试对接**：先对 1 个已知活性化合物跑 exhaustiveness=8，确认打分与构象合理（负值、配体在口袋内）再批量。
4. **批量执行**：逐个 `vina_dock`（exhaustiveness 默认 8；首轮筛选可用 1~4 提速）；记录每个配体的最佳亲和能与前 3 模式。
5. **汇总**：表格输出——配体名 | 最佳亲和能(kcal/mol) | mode 数 | 输出文件路径；按亲和能升序。
6. **结果解读**（经验参考，标注为经验值）：
   - < -9 通常视为强结合候选；-7 ~ -9 中等；> -5 一般视为弱/无意义
   - 打分函数误差 ±2 kcal/mol 量级，**必须**提醒用户打分排序不能等同活性排序，top 命中需实验/MD 验证。

## 原则

- 每次对接的种子（seed）固定以保证可复现，并在报告中记录。
- 批量超过 50 个时主动询问用户是否降 exhaustiveness 或分批。
- 质子化状态/互变异构体未处理时明确告知用户这一局限。
